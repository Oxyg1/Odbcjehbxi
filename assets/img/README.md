# Фотографии

Здесь лежат **заглушки** — тёмные градиентные картинки нужных пропорций.
Они настоящие файлы, поэтому вёрстка не ломается и не прыгает.

Чтобы поставить реальные фото, положите свои снимки **под теми же именами**:
код менять не нужно.

| Файл             | Что на фото                          | Пропорции | Размер   |
|------------------|--------------------------------------|-----------|----------|
| `hero-food.jpg`  | Крупный кадр бургера или шаурмы       | 16:11     | 1600×1100 |
| `tea.jpg`        | Заваривание чая, чайник, листовой чай | 4:3       | 1200×900 |
| `room.jpg`       | Зал кафе                              | 4:3       | 1200×900 |
| `og-cover.jpg`   | Обложка для ссылок в мессенджерах     | 1.91:1    | 1200×630 |

Пропорции важны: в CSS у каждого снимка задан `aspect-ratio`, кадр обрезается
по центру (`object-fit: cover`). Если пропорции сильно другие, что-то важное
может уйти за границу — проверьте после замены.

Перед загрузкой сожмите изображения (например, squoosh.app), цель — до 300 КБ
на файл.

**Тексты `alt`** прописаны в `index.html` рядом с каждым `<img>` и описывают
ожидаемый кадр. Если поставите другое фото, поправьте описание: его читают
вслух незрячим гостям и его же индексируют поисковики.

**Логотип.** В шапке (`index.html`, блок `.brand-mark`) и в `favicon.svg`
стоит нейтральная иконка-заглушка, а не фирменный знак «Кутуза». Замените.
