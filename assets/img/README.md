# Фотографии

Сюда кладутся снимки заведения. Пока файла нет, на сайте показывается
аккуратный градиент с подписью — вёрстка не ломается.

Ожидаемые имена файлов (JPG или WebP, переименуйте расширение в разметке,
если используете WebP):

|------------------|--------------------------------------|----------------------|
| `hero-burger.jpg`| Крупный кадр бургера «Зверь»         | 1600×1000            |
| `tea-pot.jpg`    | Чайник с завариванием                | 800×800              |
| `interior.jpg`   | Зал кафе                             | 800×800              |
| `rolls.jpg`      | Рулетики с говядиной (новинка)       | 1000×700             |

| `tea-shelf.jpg`  | Полки с чаем                         | 900×600              |
| `gallery-1.jpg`  | Зал / интерьер                       | 800×600              |
| `gallery-2.jpg`  | Бургеры                              | 800×600              |
| `gallery-3.jpg`  | Вход, дом 13/14                      | 800×600              |
| `gallery-4.jpg`  | Чайная                               | 800×600              |

Перед загрузкой сожмите изображения (например, squoosh.app) — цель до 300 КБ
на файл. Логотип заведения замените в `assets/img/favicon.svg` и в шапке
`index.html` (блок `.brand-mark`) — сейчас там нейтральная иконка-заглушка,
а не оригинальный логотип «Кутуза».
