# Telegram-бот для вашего TON-кошелька

Управляет кошельком, найденным через `ton-vanity` (v5R1 или v4R2): баланс, адрес для пополнения, отправка TON, история.
Бот отвечает **только вам** (по Telegram ID), каждая отправка подтверждается кнопкой.

## Установка (Windows)

1. Установите Python: `winget install Python.Python.3.12`, затем закройте и откройте PowerShell заново.
2. В папке `bot`: `pip install -r requirements.txt`
3. В Telegram: у **@BotFather** создайте бота (`/newbot`) и получите токен; у **@userinfobot** узнайте свой числовой ID.
4. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` - токен бота;
   - `OWNER_ID` - ваш Telegram ID;
   - `WALLET_SEED` - 64 hex-символа из строки `private seed:` в `found.txt`;
   - `WALLET_VERSION` - `v5` или `v4` (какую версию вы искали);
   - `WALLET_ADDRESS` - ваш адрес `...pulse` (проверка, что seed и версия верные).
5. Проверка без запуска бота: `python ton_bot.py --check` - должна написать «адрес совпал» и показать баланс.
6. Запуск: `python ton_bot.py`. Окно должно оставаться открытым (или запустите на сервере/VPS).

В Telegram откройте своего бота и нажмите `/start`.

## Что умеет
- 💰 **Баланс** (в TON и примерно в долларах), 📥 **Пополнить** (адрес для копирования; пока кошелёк не активирован, показывает форму `UQ…`, после активации - красивый адрес `…pulse`), 📤 **Отправить** (адрес → сумма → комментарий → подтверждение), 🕘 **История**.
- Первая отправка сама активирует кошелёк.
- Адрес проверяется по контрольной сумме (опечатка не пройдёт), адрес другой сети отклоняется, сумма проверяется с запасом на комиссию (≈0.02 TON).

## Безопасность - обязательно прочитайте
- В `.env` лежит **приватный ключ**. Тот, кто получит этот файл или доступ к компьютеру, заберёт все деньги. Не выкладывайте `.env` (он в `.gitignore`), не пересылайте.
- Если взломают ваш Telegram-аккаунт, бот выполнит команды злоумышленника. Включите в Telegram двухэтапную проверку (облачный пароль) и держите на кошельке не больше, чем готовы рисковать. Для страховки задайте `MAX_SEND_TON` - лимит одного перевода.
- Бот молча игнорирует всех, кроме `OWNER_ID`. Токен бота тоже секрет: если он утёк, перевыпустите его у @BotFather (`/revoke`).
- Подтверждение действует 2 минуты и срабатывает один раз (двойное нажатие не отправит дважды).

## Ограничения
- Только переводы TON. **Жетоны (USDT и др.), NFT, обмен, стейкинг - не поддерживаются.** Если на адрес придут жетоны, бот их не покажет и отправить не сможет.
- Нет «отправить весь баланс»: введите сумму, оставив ≈0.02 TON на комиссию.
- Нет доступа к 24 словам: это бот-интерфейс к ключу, а не импорт в Tonkeeper.

## Как проверено
Юнит-тесты (`python test_bot.py`) гоняют полный диалог через настоящий aiogram-диспетчер с подставным Telegram и поддельным кошельком: отправка, двойное нажатие, просроченное и чужое подтверждение, проверки адреса и суммы, игнорирование посторонних. Отдельно на основной сети проверены: адрес из seed (v5 и v4) совпадает с независимой библиотекой, чтение баланса и истории, сборка подписанного сообщения (подпись проверена вручную). **Не проверено:** работа с настоящим Telegram и реальная отправка денег. Первый раз отправьте на свой другой кошелёк не больше 0.1 TON.
