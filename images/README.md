# Изображения

Все файлы в этой папке, кроме `og-preview.jpg`, — **временные плейсхолдеры** (SVG
с цветной заливкой и подписью). Замените их на реальные фотографии ресторана.

## Как заменить

1. Подготовьте фото (советы по размерам — в таблице ниже), сохраните в JPG.
2. Положите файл в эту папку **с тем же именем**, но со своим расширением
   (например, `menu-pizza-margherita.jpg`).
3. В `index.html` замените расширение `.svg` на `.jpg` в соответствующем `src`
   (быстрее всего — поиск и замена `images/имя-файла.svg` → `images/имя-файла.jpg`).
4. Проверьте `alt` — он уже описывает содержимое, менять его нужно, только если
   изменился сюжет фото.

Логотип (`images/logo.svg`) — это не фото, а векторный знак заведения. Он
подставляется отдельно, инструкция — прямо в `index.html` над строкой с логотипом.

## Советы по съёмке

- **Свет:** снимайте блюда при дневном свете у окна или под тёплым тёплым светом
  зала — вспышка в лоб убивает фактуру еды.
- **Ракурс блюд:** три четверти сверху (~45°) читается лучше, чем строго сверху
  или строго сбоку.
- **Формат:** JPG, сжатие среднее-высокое — сайт не грузит эти файлы отдельно
  для мобильных, поэтому большой вес каждой картинки бьёт по скорости.
- **Горизонт:** для галереи и меню — ровный горизонт и не заваленные вертикали
  (особенно на кадрах интерьера).
- Все фото, кроме `hero-trattoria`, загружаются лениво (`loading="lazy"`) —
  на скорость первой отрисовки страницы почти не влияют.

## Логотип

Фирменный знак уже подставлен в шапку на обеих страницах:

- `logo.svg` — горизонтальный лок (ветка + «Про Италия» / «траттория»),
  используется в `<img class="logo__img">` в шапке. Один сплошной
  цвет `#5b421d`, без подложки — рассчитан на светлый фон.
- `logo-badge.svg` — исходный квадратный вариант с рамкой и заливкой
  (512×512), пока нигде не используется. Может пригодиться для фавикона
  или печатных материалов, если понадобится компактная версия-печать.

Оба файла — предоставлены заказчиком, для сайта не редактировались
(кроме обрезки `viewBox` у `logo.svg` под фактические границы рисунка
и чистки служебных атрибутов CorelDRAW/Illustrator — видимые контуры
и цвета не менялись).

Для подвала сайта (тёмный фон) используется не этот файл, а текстовый
лок, стилизованный под тот же бренд — `logo.svg` залит тёмно-коричневым
без учёта фона, на тёмно-зелёном подвале был бы низкоконтрастным.
Если заказчик пришлёт светлую версию логотипа — можно подставить
и в подвал тем же способом.
