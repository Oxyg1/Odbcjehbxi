# Изображения

Все файлы в этой папке — **временные плейсхолдеры** (SVG с подписью). Замените их
на реальные фотографии ресторана.

## Как заменить

1. Подготовьте фото (советы по размерам — в таблице ниже), сохраните в JPG или WebP.
2. Положите файл в эту папку **с тем же именем**, но со своим расширением
   (например, `menu-pizza-margherita.jpg`).
3. В `index.html` замените расширение `.svg` на `.jpg` в соответствующем `src`
   (быстрее всего — поиск и замена `images/имя-файла.svg` → `images/имя-файла.jpg`).
4. Проверьте `alt` — он уже описывает содержимое, менять его нужно, только если
   изменился сюжет фото.

Для Open Graph (`og-preview`) лучше использовать растровый формат — многие
соцсети не показывают SVG в превью.

Все изображения, кроме фона первого экрана, загружаются лениво
(`loading="lazy"`), поэтому на скорость первой загрузки почти не влияют.
