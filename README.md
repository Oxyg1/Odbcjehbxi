# PlsDonate

Telegram Mini App: свой стенд из своих стикеров и донаты в Stars и TON.

Архитектура и этапы — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Что уже работает

Конструктор стенда (этап 1):

- холст в пропорциях Stories, слои из инвентаря;
- перетаскивание, поворот на любой угол и масштаб — двумя пальцами или угловой ручкой,
  с притяжением к шагу 15° и haptic-откликом;
- порядок слоёв: соседние шаги на канвасе, полная стопка в листе «Слои»;
- отмена и повтор, автосохранение черновика;
- защищённые зоны сверху и снизу с затемнением вместо запрета;
- индикатор бюджета анимации с подтверждением при превышении.

Стенд хранится списком слоёв (`StandDoc`), а не картинкой.

Инвентарь пока временный: свободная загрузка открывается на этапе 3, вместе с
автофильтром модерации.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # типы и продакшен-сборка
npm run typecheck
```

`?perf=1` в адресе включает счётчик кадров — им проверяется сценарий с 5–8
анимированными слоями на среднем Android.
