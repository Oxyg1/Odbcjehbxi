# Кутуза

Сайт стрит-фуд кафе «Кутуза» — Москва, Кутузовский проспект, 36 с13/14.

React 18 + TypeScript + Vite + Tailwind CSS 4.

## Запуск

```bash
npm install
npm run dev        # локальный сервер на http://localhost:3000
npm run build      # типы + прод-сборка в dist/
npm run preview    # посмотреть собранное
npm run typecheck  # только проверка типов
```

## Где что лежит

| Файл | Что внутри |
|---|---|
| `src/data.ts` | Меню, отзывы, контакты, рейтинг и **расписание работы** |
| `src/hooks.ts` | Время по Москве, статус «открыто», счётчики, ловушка фокуса |
| `src/components/` | Секции страницы |
| `src/index.css` | Токены темы, анимации, стили фокуса |

### Расписание

Часы работы заданы одним массивом `SCHEDULE` в `src/data.ts` (индекс —
день недели, `0` — воскресенье). От него зависят и бейдж «открыто / откроется»,
и слоты самовывоза в форме предзаказа. Меняется в одном месте.

Те же часы продублированы разметкой `schema.org/Restaurant` в `index.html` —
при изменении расписания правьте оба места.

### Фотографии

Снимки блюд подключены по внешним ссылкам (`IMG` в `src/data.ts`). Если ссылка
не отвечает, `SmartImage` рисует подложку в цветах сайта вместо пустого места.

У раздела «Салаты и супы» своего снимка пока нет — там намеренно стоит
подложка. Как появится фото, добавьте его в `IMG` и пропишите `image` категории.
