# Сайт банкетного зала «Кондырев» (г. Кондрово)

Одностраничный сайт-визитка на чистых HTML, CSS и JavaScript — без сборщиков,
фреймворков и зависимостей. Достаточно скопировать файлы на любой статический
хостинг, и сайт работает.

**Что уже готово:** адаптивная вёрстка (mobile-first), галерея с лайтбоксом,
форма заявки с проверкой полей и маской телефона, SEO-теги, Open Graph,
микроразметка Schema.org, карта, кнопка звонка на мобильных.

---

## 1. Структура файлов

```
index.html            Главная страница — весь контент и микроразметка
thanks.html           Страница «Спасибо за заявку» (цель для Яндекс.Метрики)
README.md             Этот файл

css/
  style.css           Все стили. В начале файла — блок :root с цветами и шрифтами

js/
  script.js           Меню, галерея, анимации, проверка и отправка формы.
                      В начале файла — блок CONFIG с почтой и телефоном

assets/
  favicon.ico         Иконка вкладки браузера
  apple-touch-icon.png Иконка для «на главный экран» на iPhone
  og-image.jpg        Картинка-превью при отправке ссылки (1200×630)
  hero/
    hall-sunset.jpg   Большое фоновое фото первого экрана
  gallery/
    gallery-01.jpg …  Фотографии зала для галереи
  menu/
    dish-01.jpg …     Фотографии блюд
```

> **Важно.** Все изображения в папке `assets/` — временные заглушки, на них
> прямо написано «ВРЕМЕННОЕ ФОТО — ЗАМЕНИТЕ СВОИМ». Замените их настоящими
> фотографиями перед публикацией сайта.

## 2. Как заменить фотографии

### Фон первого экрана (hero)

Положите своё фото под именем `assets/hero/hall-sunset.jpg` — оно подхватится
само. Подойдёт горизонтальный кадр зала с панорамными окнами, лучше на закате.

| Параметр | Рекомендация |
|---|---|
| Размер | 1920 × 1280 px |
| Формат | JPG |
| Вес | до 400 КБ |

Поверх фото лежит затемнение, поэтому светлый заголовок читается на любом кадре.

### Галерея

1. Сложите фотографии в `assets/gallery/` с именами `gallery-01.jpg`,
   `gallery-02.jpg` и так далее.
2. Рекомендуемый размер — 1600 × 1067 px (пропорции 3:2), вес до 300 КБ.
3. Если фотографий больше восьми, откройте `index.html`, найдите секцию
   `<!-- 7. ГАЛЕРЕЯ -->` и скопируйте блок ещё раз, поменяв номер файла,
   подпись и alt:

```html
<li class="gallery__item reveal">
  <a class="gallery__link" href="assets/gallery/gallery-09.jpg" data-caption="Подпись под фото">
    <img src="assets/gallery/gallery-09.jpg" width="1200" height="800" loading="lazy" decoding="async"
         alt="Короткое описание того, что на фото">
  </a>
</li>
```

- `data-caption` — подпись, которая видна при открытии фото на весь экран.
- `alt` — описание для поисковиков и незрячих посетителей. Пишите по делу:
  «Свадебное оформление банкетного зала в Кондрово», а не «фото 9».
- `loading="lazy"` оставьте: фотографии подгружаются по мере прокрутки,
  и страница открывается быстрее.

Порядок листания в лайтбоксе совпадает с порядком блоков в HTML.

### Фото блюд

Файлы `assets/menu/dish-01.jpg` … `dish-04.jpg`, пропорции 4:3 (около 900 × 700 px).
Названия и описания блюд — в секции `<!-- 6. МЕНЮ / КУХНЯ -->` файла `index.html`.

### Картинка-превью для мессенджеров (og-image)

`assets/og-image.jpg`, ровно **1200 × 630 px**. Именно она показывается, когда
ссылку на сайт отправляют в WhatsApp, Telegram или ВКонтакте. Сделайте её
осмысленной: фото зала + название + телефон.

### Иконка сайта (favicon)

`assets/favicon.ico` (16/32/48/64 px в одном файле) и `assets/apple-touch-icon.png`
(180 × 180 px). Сгенерировать оба можно на любом онлайн-сервисе по одной картинке.

## 3. Как изменить тексты

Весь текст лежит прямо в `index.html`. Секции подписаны крупными комментариями,
их легко найти поиском (Ctrl+F):

| Ищите комментарий | Что меняется |
|---|---|
| `1. ШАПКА` | Логотип, пункты меню |
| `2. HERO` | Главный заголовок, подзаголовок, кнопки, факты |
| `3. О ЗАЛЕ` | Описание зала и плитка фактов |
| `4. УСЛУГИ` | Форматы мероприятий и цены |
| `5. ЧТО ВХОДИТ` | Список того, что входит в организацию |
| `6. МЕНЮ / КУХНЯ` | Блюда и их описания |
| `7. ГАЛЕРЕЯ` | Фотографии |
| `8. ОТЗЫВЫ` | Отзывы гостей и рейтинг |
| `9. КАК ДОБРАТЬСЯ` | Адрес, телефон, режим работы, оплата |
| `10. ФОРМА ЗАЯВКИ` | Поля формы и текст рядом с ней |
| `11. ФУТЕР` | Подвал сайта |

### Что обязательно проверить перед публикацией

Всё, что требует вашего решения, помечено в коде комментарием
`<!-- TODO: заменить -->`. Найдите их поиском по слову **TODO** — в HTML, CSS и JS.
Основное:

1. **Цены в услугах.** Сейчас везде стоит «Цена — по запросу». Замените на
   реальные, например `от 2 500 ₽ / гость`:
   ```html
   <p class="service-card__price">от 2 500 ₽ / гость</p>
   ```
2. **Отзывы.** Тексты в секции отзывов — пересказ своими словами, имена условные.
   Замените на настоящие отзывы (с согласия авторов) и настоящие имена.
3. **Домен.** В `<head>` файла `index.html` в тегах `canonical`, `og:url`,
   `og:image` и в микроразметке стоит `https://example.com/`. Замените на свой
   адрес — иначе превью ссылки в мессенджерах не заработает.
4. **Почта для заявок.** См. раздел 5 ниже.
5. **Ссылка на карточку в Яндекс.Картах.** В секции отзывов стоит ссылка на
   поиск. Замените на прямую ссылку на карточку организации.

## 4. Как изменить телефон, адрес и ссылки

Телефон встречается в нескольких местах, и в каждом — **в двух видах**:
как текст для человека и как ссылка `tel:` для набора номера.

Замените по всему проекту (поиск с заменой во всех файлах):

| Найти | Заменить на |
|---|---|
| `+7 (920) 876-02-22` | ваш номер в том же виде |
| `tel:+79208760222` | `tel:` + номер без пробелов и скобок |
| `+7-920-876-02-22` | ваш номер (только в микроразметке Schema.org) |
| `vk.ru/kondyrev_zal` | адрес вашей группы |
| `ул. Интернациональная, 25` | ваш адрес |

Телефон также продублирован в `js/script.js` → `CONFIG.phone` и `CONFIG.phoneHref` —
оттуда он подставляется в сообщения формы.

### Карта

В секции контактов стоит виджет Яндекс.Карт с поиском по адресу. Чтобы метка
встала точно на здание:

1. Откройте <https://yandex.ru/map-constructor/>
2. Найдите свой адрес, поставьте метку, нажмите «Получить код карты».
3. Скопируйте из полученного кода значение `src="…"`.
4. Вставьте его в `index.html` вместо текущего `src` у `<iframe class="map__frame">`.

## 5. Куда приходят заявки

**Сейчас** форма работает через `mailto`: при отправке у посетителя открывается
его почтовая программа с уже заполненным письмом, и он нажимает «Отправить».
Это работает без сервера, но часть заявок теряется — на телефоне почтовый клиент
настроен не у всех.

Минимум, что нужно сделать: открыть `js/script.js` и вписать свою почту:

```js
var CONFIG = {
  email: 'zakaz@example.com',   // ← сюда вашу почту
  ...
};
```

**Как сделать надёжно.** В `js/script.js` найдите комментарий
`ПОДКЛЮЧЕНИЕ БЭКЕНДА` — там расписаны три готовых варианта:

| Вариант | Кому подходит | Сложность |
|---|---|---|
| **Telegram-бот** | Заявка мгновенно падает в чат на телефон | 10 минут, без сервера |
| **Formspree / Getform** | Заявки приходят на почту, есть архив | 5 минут, без сервера |
| **Свой обработчик** (PHP/CRM) | Если хостинг с PHP или уже есть CRM | нужен программист |

> Учтите: токен Telegram-бота, вписанный прямо в `script.js`, виден любому
> посетителю сайта. Для боевого использования запрос лучше проводить через
> собственный скрипт на сервере.

При любом варианте оставьте переход на `thanks.html` — по нему удобно считать
заявки в аналитике.

### Персональные данные

В форме есть галочка согласия на обработку персональных данных. Как только вы
начнёте реально принимать и хранить заявки, добавьте на сайт страницу с политикой
обработки персональных данных и поставьте на неё ссылку — место под неё помечено
комментарием `TODO` в футере `index.html`.

## 6. Как изменить цвета и шрифты

Откройте `css/style.css` — в самом верху блок `:root`. Меняете значение в одном
месте, оно подхватывается по всему сайту:

```css
:root {
  --gold:       #C9A227;   /* приглушённое золото — кнопки и акценты */
  --cream:      #F7F1E6;   /* тёплый беж — фон секций */
  --graphite:   #231F20;   /* тёмный графит — текст и подвал */
  --burgundy:   #6E1B2B;   /* бордовый — заголовки и ссылки */

  --font-display: "Cormorant Garamond", ...;  /* заголовки */
  --font-text:    "Manrope", ...;             /* основной текст */
}
```

Шрифты подключены с Google Fonts в `<head>` обоих HTML-файлов. Хотите другие —
выберите пару на <https://fonts.google.com>, замените там ссылку `<link>` и
названия в `--font-display` / `--font-text`. Обязательно проверьте, что у шрифта
есть кириллица.

## 7. Локальный просмотр

Просто открыть `index.html` двойным кликом можно, но правильнее поднять
локальный сервер — тогда корректно работают шрифты, карта и относительные пути.

```bash
# в папке проекта
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.

**Проверка на телефоне.** Узнайте локальный адрес компьютера и откройте его
с телефона, подключённого к той же сети Wi-Fi:

```bash
hostname -I          # Linux
ipconfig getifaddr en0   # macOS
ipconfig             # Windows — строка «IPv4-адрес»
```

Адрес будет вида `http://192.168.1.15:8000`.

## 8. Как выложить сайт в интернет

### Вариант А. Netlify (бесплатно, самый быстрый)

1. Зайдите на <https://app.netlify.com/drop>.
2. Перетащите туда **папку целиком** (не архив).
3. Сайт сразу доступен по адресу вида `random-name.netlify.app`.
4. Свой домен: *Site settings → Domain management → Add custom domain*.

### Вариант Б. Vercel

1. Установите: `npm i -g vercel`
2. В папке проекта: `vercel` — и следуйте подсказкам.
3. Публикация обновления: `vercel --prod`

### Вариант В. GitHub Pages (бесплатно)

1. Загрузите файлы в репозиторий на GitHub.
2. *Settings → Pages → Source: Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://ваш-логин.github.io/имя-репозитория/`.

### Вариант Г. Обычный хостинг (Timeweb, reg.ru, Beget и т.п.)

Подключитесь по FTP и скопируйте **всё содержимое папки** (`index.html`,
`thanks.html`, папки `css`, `js`, `assets`) в корневую директорию сайта —
обычно она называется `public_html` или `www`. Никакой настройки не требуется:
PHP, база данных и Node.js сайту не нужны.

### После публикации — обязательно

1. Замените `https://example.com/` на реальный домен в `index.html`
   (теги `canonical`, `og:url`, `og:image` и микроразметка Schema.org).
2. Проверьте превью ссылки: <https://vk.com/dev/pages.clearCache> (ВКонтакте)
   или просто отправьте ссылку себе в мессенджер.
3. Проверьте микроразметку: <https://validator.schema.org/>
4. Добавьте сайт в Яндекс.Вебмастер и укажите его в карточке организации
   на Яндекс.Картах — это заметно поднимает сайт по локальным запросам.
5. Подключите Яндекс.Метрику (код вставляется перед `</head>`) и заведите цель
   «Посещение страниц» с условием: url содержит `thanks.html`.

## 9. Что учтено в коде

- **Адаптивность.** Вёрстка mobile-first, проверена на ширинах 320, 390, 768
  и 1440 px. Горизонтальной прокрутки нет ни на одной из них.
- **Скорость.** Фон первого экрана грузится приоритетно, все остальные
  изображения — по мере прокрутки (`loading="lazy"`). У каждой картинки заданы
  `width` и `height`, поэтому страница не «прыгает» при загрузке.
- **SEO.** Заполнены `title`, `description`, Open Graph и микроразметка
  Schema.org `EventVenue` + `LocalBusiness` с адресом, телефоном, часами работы,
  вместимостью и рейтингом.
- **Доступность.** Сайт работает с клавиатуры, у всех изображений есть `alt`,
  у иконок и кнопок — понятные подписи для скринридеров.
- **Работа без JavaScript.** Если скрипты отключены, страница остаётся читаемой:
  фотографии в галерее открываются обычными ссылками, а рядом с формой
  появляется просьба позвонить.
- **Бережные анимации.** Если в системе включено «уменьшить движение»,
  анимации и параллакс автоматически отключаются.

## 10. Частые вопросы

**Сайт открывается, но шрифты выглядят иначе.**
Google Fonts недоступны — например, нет интернета или их блокирует провайдер.
Сайт останется читаемым: подставятся системные шрифты. Если это повторяется,
скачайте шрифты и положите их в `assets/fonts/`, подключив через `@font-face`.

**Вместо карты пустая рамка.**
Виджет Яндекс.Карт не грузится при открытии файла двойным кликом (`file://`).
Поднимите локальный сервер — см. раздел 7.

**Фотографии не поменялись.**
Браузер держит старые в кэше. Обновите страницу с Ctrl+F5 (Cmd+Shift+R на Mac).

**Как добавить ещё одну услугу?**
В секции `<!-- 4. УСЛУГИ -->` скопируйте любой блок `<li class="service-card ...">`
и поменяйте в нём иконку, заголовок, описание и цену. Сетка перестроится сама.
