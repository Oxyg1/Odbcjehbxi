# Сайт кафе «Кутуза»

Одностраничный сайт кафе-чайной «Кутуза» (Москва, Кутузовский просп., 36с13/14).
Статика без сборки: HTML + CSS + немного ванильного JS. Открывается двойным
кликом по `index.html`, разворачивается на любой хостинг или GitHub Pages.

## Структура

```
index.html               разметка страницы и микроразметка Schema.org
assets/css/styles.css    все стили, палитра — в :root
assets/js/menu-data.js   МЕНЮ: блюда, цены, составы (правится здесь)
assets/js/main.js        контакты, вкладки меню, навигация, анимации
assets/img/              фотографии (см. assets/img/README.md)
```

## Что нужно заполнить перед публикацией

1. **Телефон.** На Яндекс.Картах номер скрыт частично («+7 (926) 988-…»).
   Подставьте полный номер в `assets/js/main.js` → `CONTACT` — он обновится
   сразу во всех ссылках (шапка, контакты, кнопка звонка, WhatsApp).
   Там же — ссылка на Telegram.
2. **Меню.** `assets/js/menu-data.js`. Сейчас внесены позиции, которые
   читаются в карточке заведения: бургеры и горячие блюда. Раздел «Закуски»
   и полные составы бургеров помечены `TODO` — дополните по факту.
3. **Фотографии.** Положите файлы в `assets/img/` под именами из
   `assets/img/README.md`. До этого на их месте — градиентные заглушки.
4. **Логотип.** В шапке и в `favicon.svg` стоит нейтральная иконка-заглушка.
   Замените на фирменный знак «Кутуза».
5. **Отзывы.** В блоке «Отзывы» — обобщённые формулировки для вёрстки.
   Замените реальными цитатами гостей (и уберите примечание под блоком).
6. **Домен.** В `index.html` замените `https://kutuza.ru/` в `<link rel=canonical>`
   и Open Graph на фактический адрес сайта.

## Публикация на GitHub Pages

Settings → Pages → Source: ветка с этим кодом, папка `/ (root)`.
Файл `.nojekyll` уже добавлен, чтобы Pages отдавал статику как есть.

## Что уже сделано

- Адаптивная вёрстка (мобильные, планшеты, десктоп), тёмная тема
- Меню с переключением категорий, доступное с клавиатуры (роль `tablist`)
- Микроразметка `Restaurant` для поиска: адрес, часы, рейтинг 4,9
- Open Graph для превью в мессенджерах
- Плавающая кнопка «Позвонить» на мобильных
- Поддержка `prefers-reduced-motion`, skip-link, видимый фокус
