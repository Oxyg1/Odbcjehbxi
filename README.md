# Сайт кафе «Кутуза»

Одностраничный сайт кафе-чайной «Кутуза» (Москва, Кутузовский просп., 36с13/14).
Статика без сборки: HTML + CSS + немного ванильного JS. Открывается двойным
кликом по `index.html`, разворачивается на любой хостинг или GitHub Pages.

**Страница полностью работает без JavaScript**: меню, цены, контакты и все
разделы отдаются в разметке. Скрипт только добавляет вкладки меню, мобильную
навигацию и подставляет телефон.

## Структура

```
index.html               разметка, меню с ценами, микроразметка Schema.org
assets/css/styles.css    стили, палитра — в :root (и в .tea для светлого зала)
assets/js/main.js        контакты, вкладки меню, навигация
assets/img/              фотографии и заглушки (см. assets/img/README.md)
PRODUCT.md               продуктовая правда: аудитория, ограничения, что нельзя выдумывать
.impeccable/critique/    отчёты дизайн-ревью
```

## Что нужно заполнить перед публикацией

1. **Телефон.** На Яндекс.Картах номер показан частично («+7 (926) 988-…»),
   поэтому на сайте его нет: выдуманных цифр в `tel:`, WhatsApp и в
   микроразметке быть не должно. Впишите настоящий номер в объект `CONTACT`
   в начале `assets/js/main.js` — появится в блоке контактов и в нижней
   кнопке звонка. Пока поле пустое, кнопка честно ведёт на карточку Яндекса.
2. **Фотографии.** Положите файлы в `assets/img/` под именами из
   `assets/img/README.md`. Сейчас там заглушки нужных пропорций.
3. **Логотип** в шапке и в `favicon.svg` — заглушка, замените на фирменный знак.
4. **Меню.** Блюда и цены правятся прямо в `index.html`, в секциях
   `.menu-cat`: это единственный источник данных, дублей нет. Составы бургеров
   в карточке Яндекса обрезаны — дополните. Раздел закусок не заполнен.
5. **Отзывы.** Настоящих цитат на руках нет, поэтому на сайте только
   проверяемые цифры (4,9 · 528 оценок · 372 отзыва) со ссылкой на Яндекс.
   Выдуманные отзывы от имени «Гостя Яндекс.Карт» публиковать нельзя.
   Пришлите реальные — добавим блок с цитатами.
6. **Домен.** Замените `https://kutuza.ru/` в `<link rel=canonical>`,
   в Open Graph и в JSON-LD на фактический адрес сайта.

## Публикация на GitHub Pages

Settings → Pages → Source: ветка с этим кодом, папка `/ (root)`.
Файл `.nojekyll` уже добавлен, чтобы Pages отдавал статику как есть.

## Качество

Сайт прогнан через [Impeccable](https://github.com/pbakaus/impeccable) —
дизайн-ревью, детектор анти-паттернов и измерения в браузере.

Проверено измерением (Chromium, 320–1440px):

- детектор анти-паттернов: чисто (единственное ложное срабатывание
  задокументировано инлайн-комментарием в `index.html`);
- контраст: 25 текстовых пар, ни одна не ниже WCAG AA; границы элементов
  управления не ниже 3:1 (WCAG 1.4.11);
- переполнения по горизонтали нет на 320, 390, 768, 1024 и 1440px;
- цели нажатия не меньше 44px, кроме ссылок внутри текста абзаца
  (исключение WCAG 2.2 для inline-ссылок);
- порядок заголовков без пропусков: h1 → h2 → h3 → h4;
- закрытое мобильное меню не ловит фокус (`inert`), открытое — принимает
  фокус, удерживает его и возвращает на кнопку по Escape;
- без JavaScript страница показывает все 14 блюд с ценами;
- `prefers-reduced-motion` отключает единственную анимацию входа.

Повторный прогон: `node <путь-к-impeccable>/scripts/detect.mjs index.html`.
