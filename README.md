## Что внутри

**Страницы**

| Файл | Что это |
|---|---|
| `index.html` | Главная: первый экран, о траттории, преимущества, хиты меню, галерея, отзывы, бронирование, доставка, контакты |
| `menu.html` | Полное меню: 10 категорий, 80 блюд, вкладки, живой поиск |
| `privacy.html` | Политика обработки персональных данных (заготовка под реквизиты) |
| `404.html` | Страница «не найдено» в стиле сайта |

**Что умеет сайт**

- **Живой статус «Открыто / Закрыто»** — считается по реальным часам работы и обновляется каждую минуту. В расписании подсвечивается сегодняшний день.
- **Меню из одного файла** — все блюда и цены лежат в `assets/js/menu-data.js`. Поменяли там — изменилось везде.
- **Поиск и фильтр по меню** — гость набирает «карбонара» и сразу видит блюдо.
- **Бронирование столика** — форма с проверкой полей, маской телефона и отправкой заявки администратору.
- **Галерея с лайтбоксом** — снимок открывается на весь экран, закрывается по Esc.
- **Карта и отзывы Яндекса** — подгружаются лениво, чтобы сайт открывался быстро.
- **Мобильная версия** — отдельное меню-шторка и нижняя панель «Позвонить / Забронировать», которая всегда под рукой.
- **SEO** — заголовки, описания, Open Graph для соцсетей, микроразметка Schema.org Restaurant, `robots.txt` и `sitemap.xml`.
- **Доступность** — навигация с клавиатуры, ARIA-подписи, контрастный текст, поддержка «уменьшить движение».
- **Печать меню** — `menu.html` корректно печатается в две колонки (Ctrl+P), можно раздавать гостям.

## Как посмотреть сайт

**Самый простой способ** — открыть `index.html` двойным кликом в браузере.

**Правильный способ** (нужен, чтобы корректно работали все ссылки) — запустить
локальный сервер из папки проекта:

```bash
# если установлен Python
python3 -m http.server 8000

# или Node.js
npx serve .
```

Затем открыть <http://localhost:8000>.

## Как менять меню

Всё меню — в файле **`assets/js/menu-data.js`**. Открывается любым текстовым
редактором (Блокнот, VS Code, Notepad++).

### Изменить цену

Найдите блюдо и поправьте число. Знак ₽ подставляется сам:

```js
{ name: 'Карбонара с гуанчале', desc: 'Спагетти, гуанчале, желток, пекорино, чёрный перец',
  weight: '300 г', price: 690, tags: ['хит'] },
//                 ↑ меняем только число
```

### Добавить блюдо

Скопируйте любую строку внутри нужной категории и поправьте:

```js
{ name: 'Тальолини с крабом', desc: 'Домашняя паста, краб, томаты, чили',
  weight: '280 г', price: 1290, tags: ['новинка'] },
```

### Убрать блюдо

Удалите его строку целиком (вместе с запятой в конце).

### Значки на карточке

| Что писать | Что покажет |
|---|---|
| `tags: ['хит']` | оранжевый значок **ХИТ** |
| `tags: ['новинка']` | зелёный значок **НОВИНКА** |
| `tags: ['остро']` | красный значок **ОСТРО** |
| `tags: ['фирменное']` | золотой значок **ФИРМЕННОЕ** |
| `veg: true` | значок 🌱 **ВЕГ** |

Значки можно совмещать: `tags: ['хит', 'остро'], veg: true`.

### Добавить целую категорию

Скопируйте блок категории целиком и поменяйте `id`, `title` и `icon`.
Доступные иконки: `breakfast`, `antipasti`, `salad`, `soup`, `pasta`,
`pizza`, `risotto`, `main`, `dessert`, `drink`.

### Поменять блюда в блоке «Что заказать в первый раз»

В самом низу файла — список `highlights`. Формат: `'категория/Точное название блюда'`.

```js
highlights: [
  'pizza/Маргарита',
  'pasta/Карбонара с гуанчале',
  ...
]
```

> Название должно совпадать с `name` блюда **до буквы**, иначе карточка не появится.

## Как менять контакты и часы работы

### Телефон и адрес

Телефон встречается в трёх видах — проще всего заменить поиском по всем файлам
(`Ctrl+H` → «Заменить во всех файлах»):

- `+7 (910) 600-22-21` — как телефон показывается гостю;
- `+79106002221` — как он записан в ссылках `tel:` и `wa.me`;
- в `assets/js/main.js`, блок `CONFIG` в самом начале файла.

### Часы работы

Меняются **в двух местах** — иначе живой статус «Открыто/Закрыто» разойдётся
с расписанием на странице:

**1. `assets/js/main.js`**, блок `CONFIG.hours` (время в минутах от полуночи):

```js
hours: {
  0: { open: 9 * 60, close: 23 * 60, label: '9:00 — 23:00' },  // воскресенье
  1: { open: 8 * 60, close: 23 * 60, label: '8:00 — 23:00' },  // понедельник
  ...
  5: { open: 8 * 60, close: 24 * 60, label: '8:00 — 00:00' },  // пятница
}
```

**2. `index.html`** — список `<ul class="hours-list">` в блоке бронирования
и раздел «Режим работы» в контактах. Плюс подвал на обеих страницах.

## Как поставить настоящие фотографии

Сейчас на сайте — фирменные иллюстрации в стиле ресторана. Как только появится
фотосъёмка блюд и интерьера, замена занимает пару минут.

### Галерея (6 снимков)

Положите фотографии в `assets/img/` и поправьте пути в `index.html`,
блок `<div class="gallery">`:

```html
<img src="assets/img/gallery-1.svg" alt="Зал и дровяная печь" ...>
<!-- меняем на -->
<img src="assets/img/zal.jpg" alt="Зал и дровяная печь" ...>
```

**Рекомендации:** горизонтальные снимки, 1600×1100 px, JPG, до 300 КБ.
Формат WebP — ещё лучше. Обязательно пишите осмысленный `alt` — его читают
поисковики и незрячие гости.

### Блюда на главной

Карточки берут картинку по категории блюда: `assets/img/dish-pizza.svg`,
`dish-pasta.svg`, `dish-antipasti.svg`, `dish-risotto.svg`, `dish-salad.svg`,
`dish-dessert.svg`. Замените эти файлы на фотографии с теми же именами —
и всё подхватится само. Пропорции 4:3, 1200×900 px.

### Зал в блоке «О траттории»

`assets/img/interior.svg` → вертикальное фото 3:4, 1200×1600 px.

### Превью для соцсетей

`assets/img/og-cover.svg` → лучше заменить на **JPG или PNG 1200×630 px**:
Telegram и ВКонтакте не показывают SVG в превью ссылок. После замены поправьте
`og:image` в `<head>` обеих страниц.

## Куда приходят заявки на бронь

Сейчас форма собирает данные и **открывает WhatsApp** администратора
с готовым текстом заявки. Работает сразу, без сервера и без хостинга с PHP —
гость нажимает «Забронировать», у него открывается чат, остаётся отправить
сообщение.

Если нужна классическая отправка на почту, есть три варианта.

**Вариант 1 — Formspree / Getform (без программиста, ~5 минут)**

1. Зарегистрируйтесь на <https://formspree.io> и получите адрес формы.
2. В `index.html` добавьте атрибуты к тегу `<form>`:
   ```html
   <form class="form" id="booking-form" novalidate
         action="https://formspree.io/f/ВАШ_КОД" method="POST">
   ```
3. В `assets/js/main.js` в обработчике `form.addEventListener('submit', ...)`
   удалите строку с `window.open('https://wa.me/...')` и вместо неё вызовите
   `form.submit()`.

**Вариант 2 — Telegram-бот.** Заявка падает в чат администратора мгновенно.
Нужен бот через `@BotFather` и один запрос `fetch()` — около десяти строк кода.

**Вариант 3 — PHP на хостинге.** Классический `mail()` или SMTP,
если хостинг это поддерживает.

> Что бы вы ни выбрали — телефон в шапке и на нижней панели работает всегда.
> Большинство броней в ресторанах всё равно приходит звонком.

## Виджеты Яндекса: карта и отзывы

Оба виджета привязаны к организации на Яндекс Картах —
идентификатор **74968518353**.

**Карта** (`index.html`, блок «Контакты»):

```html
<iframe data-src="https://yandex.ru/map-widget/v1/?oid=74968518353&ol=biz&z=17" ...>
```

**Отзывы** (`index.html`, блок «Отзывы»):

```html
<iframe data-src="https://yandex.ru/maps-reviews-widget/74968518353?comments" ...>
```

Отзывы подтягиваются с Яндекс Карт автоматически — их не нужно обновлять руками,
и в них нельзя ничего «подправить». Это честно и вызывает доверие.

Если понадобится пересобрать виджет (например, поменять размер или тему) —
конструкторы здесь:
<https://yandex.ru/business/widget/constructor/maps> и
<https://yandex.ru/business/widget/constructor/reviews>.

> Виджеты загружаются лениво — только когда гость доскроллил до них.
> Поэтому сайт открывается быстро даже на слабом интернете.

**Рейтинг 5,0 и «1 661 оценка»** записаны в `index.html` текстом (первый экран
и карточка в блоке отзывов). Цифры со временем меняются — раз в несколько
месяцев их стоит сверять с Яндекс Картами.

## Публикация на хостинге

Сайт статический, поэтому подойдёт любой хостинг.

**Бесплатно и за минуту** — [Netlify Drop](https://app.netlify.com/drop):
перетащите папку проекта в окно браузера, получите рабочую ссылку.
Свой домен подключается в настройках.

**GitHub Pages** — Settings → Pages → Deploy from branch. Сайт будет доступен
по адресу вида `https://<аккаунт>.github.io/<репозиторий>/`.

**Обычный хостинг (reg.ru, timeweb, beget)** — загрузите содержимое папки
по FTP в корень сайта (`public_html` или `www`). Ничего настраивать не нужно.

Для красивых адресов без `.html` (`/menu` вместо `/menu.html`) на Apache-хостинге
создайте в корне файл `.htaccess`:

```apache
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_FILENAME}\.html -f
RewriteRule ^(.*)$ $1.html [L]
ErrorDocument 404 /404.html
```

## Технические детали

- **Стек:** HTML5, CSS3 (Grid, Flexbox, custom properties), JavaScript ES5+.
  Ноль зависимостей, ноль сборки.
- **Вес страницы:** около 80 КБ без учёта шрифтов и виджетов Яндекса.
- **Шрифты:** Playfair Display и Manrope с Google Fonts, с системными
  запасными вариантами — если шрифты не загрузятся, сайт останется читаемым.
- **Браузеры:** Chrome, Safari, Firefox, Edge, Яндекс Браузер — актуальные
  версии, включая мобильные. На старых браузерах анимации отключаются,
  содержимое остаётся доступным.
- **Адаптивность:** проверено на 390 px (телефон), 768 px (планшет),
  1440 px и шире (десктоп). Горизонтальной прокрутки нет ни на одном размере.
- **Доступность:** переход по Tab, «пропустить к содержимому», ARIA-подписи,
  видимый фокус, поддержка `prefers-reduced-motion`.
- **Производительность:** тяжёлые iframe грузятся лениво, картинки — с
  `loading="lazy"`, анимации только на `transform` и `opacity`.
