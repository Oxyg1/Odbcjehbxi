# Траттория «Pro Italia» — лендинг

Одностраничный адаптивный сайт итальянской траттории «Pro Italia» (г. Калуга, ул. Ленина, 86).

Чистые HTML5 + CSS3 + vanilla JS. Без фреймворков, сборщиков и npm-зависимостей —
`index.html` открывается двойным кликом и работает как есть.

## Структура

```
/
├── index.html      разметка всех секций + микроразметка Schema.org
├── privacy.html    политика обработки персональных данных (152-ФЗ)
├── styles.css      стили (переменные, секции, адаптив — оглавление в начале файла)
├── script.js       хедер, бургер-меню, анимации, лайтбокс, валидация формы
├── menu/           PDF с полным меню (открывается кнопкой в разделе «Меню»)
└── images/         SVG-плейсхолдеры + инструкция по замене (images/README.md)
```

## Как посмотреть

Откройте `index.html` в браузере. Либо поднимите локальный сервер (нужен, если хотите
проверить карту и шрифты в «боевых» условиях):

```bash
npx serve .          # или: python3 -m http.server 8000
```

## Что реализовано

- **Секции:** хедер → hero → о ресторане → меню → галерея → отзывы → бронирование →
  доставка → контакты с картой → футер.
- **Адаптив:** брейкпоинты 1200 / 992 / 860 (мобильное меню) / 768 / 560 / 380 px.
- **Анимации:** появление секций через `IntersectionObserver`, плавный скролл к якорям,
  подсветка активного пункта меню. Уважается `prefers-reduced-motion`.
- **Галерея:** лайтбокс с навигацией стрелками, свайпами, закрытием по Esc и клику по фону,
  с возвратом фокуса и «ловушкой» фокуса внутри окна.
- **Форма брони:** маска телефона, запрет прошедших дат, валидация всех полей с понятными
  сообщениями, инлайн-подтверждение после отправки.
- **График работы:** расписание по дням недели + индикатор «сейчас открыто / закрыто»,
  который считает время по `Europe/Moscow`, поэтому корректен для гостя из любого пояса.
- **Навигация по длинной странице:** кнопка «Пропустить меню» появляется, пока гость
  внутри самого длинного раздела, и уводит к галерее. Автовосстановление прокрутки
  браузером отключено — страница всегда открывается сверху, а вернуться к прочитанному
  предлагает подсказка внизу (позиция живёт в `sessionStorage` 30 минут).
- **SEO:** title, description, canonical, Open Graph и Twitter Card, семантичная разметка,
  `alt` у всех изображений, JSON-LD `Restaurant` с рейтингом 5.0 / 1725 оценок
  и `openingHoursSpecification`.
- **Доступность:** skip-link, `aria-label` у иконочных кнопок, `aria-expanded` у бургера,
  видимые фокус-стили, `role="status"` для результата отправки формы.
- **Производительность:** `loading="lazy"` у всех изображений кроме фона первого экрана,
  из внешних зависимостей — только Google Fonts и виджет Яндекс.Карт.

## Что нужно доделать перед запуском

1. **Фотографии.** Все картинки в `images/` — плейсхолдеры. Инструкция по замене и таблица
   размеров: [`images/README.md`](images/README.md).
2. **Актуальность PDF-меню.** В `menu/pro-italia-menu.pdf` лежит версия, присланная
   заказчиком. Учтите: в ней на каждой странице есть промокод «LETO20» со сроком
   до 20.07.26 — он уже истёк. Попросите у клиента свежий файл и положите его
   с тем же именем, ссылка в разметке менять не потребуется.
   Файл весит 4,9 МБ (150 dpi, уже сжат) — если для мобильных нужно легче,
   пусть клиент выгрузит версию под веб.
3. **Реквизиты в политике ПДн.** В `privacy.html`, раздел 2, не заполнены наименование
   юрлица/ИП, ИНН, ОГРН, юридический адрес и e-mail для обращений — мы не выдумывали их.
   На странице они подсвечены пунктирной рамкой, пропустить невозможно. Заполните
   до публикации на рабочем домене и покажите документ юристу заказчика.
4. **Отправка формы.** Сейчас демо-режим: заявка выводится в консоль и показывается
   подтверждение. В `script.js` в обработчике `submit` есть блок комментариев с готовыми
   вариантами подключения (Formspree, свой API/Telegram-бот, PHP-обработчик).
   Токен Telegram-бота держите на стороне сервера — в коде сайта его публиковать нельзя.
5. **Домен.** Замените `https://proitalia-kaluga.ru/` в `canonical` и Open Graph на реальный,
   а `og:image` — на растровое превью (соцсети не показывают SVG).
6. **Карта.** Сейчас подставлен виджет по адресу «Калуга, улица Ленина, 86». Для карточки
   организации: Яндекс.Карты → «Поделиться» → «Код для сайта» → вставьте `src` в iframe.
   Если карта не загрузилась, под ней показывается запасной блок со ссылкой.

## Деплой

Статика без сборки — подойдёт любой хостинг:

- **Netlify / Vercel / Cloudflare Pages:** подключить репозиторий, build command оставить
  пустым, publish directory — корень.
- **GitHub Pages:** Settings → Pages → Deploy from branch.
- **Обычный shared-хостинг:** скопировать все файлы в `public_html` по FTP.
